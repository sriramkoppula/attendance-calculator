# 📚 Attendify - Smart Attendance Calculator

Attendify is a simple and user-friendly web application that helps students calculate their attendance percentage and plan how to improve their attendance.

It also provides a recovery planner and future attendance projections.

## 🚀 Live Demo

https://sriramkoppula.github.io/attendance-calculator/

## ✨ Features

- 📊 Calculate current attendance percentage
- 🎯 Set a custom target attendance
- ⚠️ Identify whether attendance is below the target
- 📚 Calculate classes required to reach the target
- 🎯 Calculate safe classes that can be missed
- 📈 Project attendance after attending the next 5 or 10 classes
- 📊 Visual attendance progress bar
- 🔄 Reset calculator
- 📱 Responsive design for mobile and desktop
- ✅ Input validation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
